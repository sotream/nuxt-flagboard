# Security policy

This is a personal portfolio project, maintained on a best-effort basis with no support commitment. Read the
ADRs and the Known limitations section of the README before reporting a documented trade-off as an issue.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private reporting: **Security** tab, then **Report a
vulnerability**. Include the affected file or route, steps to reproduce and the impact.

Reports are read when time allows; there is no response-time guarantee. Fixes land on `main`, and only the
latest commit on `main` is supported.

## Scope

In scope: the code in this repository. Out of scope: vulnerabilities in third-party dependencies (report them
upstream) and the documented trade-offs, such as access tokens staying valid until they expire.
